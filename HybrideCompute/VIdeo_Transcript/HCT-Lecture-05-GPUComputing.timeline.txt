เทคโนโลยีวันนี้

โดยก็คงจะพยายามอธิบายอ้างอิงกับหลักการทำงานของ CPU ที่ได้อธิบายไปก่อนหน้านี้แล้ว

โดยจะพยายามชี้ให้เห็นหลักการทำ Parallel Processing อย่างที่เคยอธิบายไปก่อนหน้านั้น
จำเอาไว้เลยนะครับ ไฮเพอร์ฟอร์เมนต์คอมพิวติ้งหลักการพื้นฐานคือทำอย่างไรให้มันพาราเลลโปรเซสซิกส์ให้มากที่สุด
แล้วเดี๋ยวจะอธิบายในเชิงสถาปติกรรมของ GPU ให้เห็นภาพ GPU Architecture ก็จะอธิบายในมุมมองเน้นออกไปทางฮาร์ดแวร์หรือ

การเขียนโปรแกรมในมุมมองของโปรแกรมนะครับโดยเริ่มต้นจากจากโครงสร้างฮาร์ดแวร์อาร์คินิเจอร์เราจะ
ได้ยังไงเขียนโปรแกรมได้อย่างไรแล้วก็มาดูชุดของซอฟต์แวร์เกี่ยวกับพวกโค้ดกับซอฟต์แวร์ development เราจะพัฒนาได้ยังไง
นะครับก็จะเป็นหัวข้อถัดไปหลังจากนั้นก็จะสรุปให้เห็นภาพโดยรวมของหัวข้อ GPU based computing technology อีกทีนึง

มันเริ่มต้นมาจากการประมวลผลการจอด นะครับ

ขอตั้งต้นจากการ์ดจอที่เรียกว่า VGA เคยได้ยินใช่ไหมครับ คุณชื่อใช่ไหมครับ

หลักการแสดงผลภาพกราฟิกยังไง ทำยังไง

นี่คือภาษา C Execute ด้วยฟังก์ชันเมน ก็คือโปรแกรมเมนหลัก
มีการเรียกฟังก์ชันในตัวอย่างนี้ก็คือชื่อเวคแอป และสั่งแตกตัวเป็นจำนวน N และตัวนี้ ABC คือพารามิเตอร์ของฟังก์ชันตัวนี้
ฝั่ง GPU Site ก็เรียกโปรแกรมขึ้นมา
พอไป Compile มันก็จะไปติดตั้งอยู่ฝั่ง GPU และนี่คือโปรแกรมที่จะทำงาน
มันก็จะเกิดการแตกตัวเป็น Thread ตามจำนวนที่สั่งออกมา M นี่ก็เป็นตัวแปลออกมา
แล้วก็แตกเป็น Parallel Processing ออกมา
ภาพการทำงานของ Nvidia มันก็จะเป็นแบบนี้ แยกส่วน ของ Nvidia ก็จะใช้ Compiler ที่ชื่อ Nvcc
ของ Nvidia แล้วในนั้นมันก็จะแตกแยกให้เองว่า อันนี้เป็น Source Code ฝั่ง Host ก็ไปเรียก Compiler ฝั่ง Host
อันนี้เป็น Source Code ฝั่ง GPU ก็ไปเรียก Compiler ฝั่ง GPU ให้เกิดการทำงานตามนั้น

ในปัจจุบันผู้ผลิตก็จะมีซอฟต์แวร์มาช่วย
พวกซอฟต์แวร์ตำรวจรูปอย่างน้อยที่สุดก็จะมีดรายเวอร์เอาไว้ติดต่อพูดคุยสั่งให้ตัวการ์ดหรือตัวดีไวซ์ทำงานได้นะครับแต่ถ้าเกิดบางผู้ผลิต
ช่วยอำนวยความสะดวก สร้างแพ็กเกจ แลมเบอรี่ หรือฟังก์ชันคอล หรือเอพีไอ ต่าง ๆ เพื่อให้เวลาเราเขียนโปรแกรมทำงานได้ง่ายขึ้น
มันก็จะมีพวกซอฟต์แวร์ต่าง ๆ มาให้เรียกใช้ เราก็ต้องไปศึกษาชุดซอฟต์แวร์ของมันว่า เวลาจะเรียกให้มันทำงาน
ต้องผ่านตัวไหนยังไงบ้าง หรือไปเรียกใช้ตัวไหนบ้าง แต่ถามว่าถ้าไม่มีพวกนี้ได้ไหม
ได้แต่เราก็จะต้องไปพัฒนาเองทั้งหมดเสียเวลาดังนั้นการที่มีพวกลายเบอรี่หรือแพ็กเกจอะไรต่างต่างก็ช่วยให้เราพัฒนาโปรแกรมพัฒนาซอฟต์แวร์ให้เกิดการทำงานได้รวดเร็วมากยิ่งขึ้นไม่ต้องทำเองใหม่ทั้งหมดนั่นนั่นเอง

นั่นก็คือเรื่องของจีพียู
จะเห็นได้ว่าโดยสรุปวันนี้การทำงานของจีพียู
เริ่มต้นมาจาก
การจอง นะครับ พัฒนาขึ้นมาอย่างที่ได้อธิบายไปตอนแรกก็เป็นเรื่องของการแสดงผลอย่างเดียว
เริ่มพัฒนาศักยภาพในการประมวลผลภาพกราฟิกขึ้นมา
พอพัฒนาขึ้นมาได้มากขึ้นมากขึ้นปุ๊บ ก็เริ่มมีแนวคิดเอาไปใช้ในการประมวลผลทั่วไปเกิดเป็นรูปแบบของ General Proposed GPU และการทำงานของมันก็ทำงานในลักษณะของ SIMD
Massively Parallel Processor อยู่ภายใน
ลักษณะเด่นของการทำงานแบบ GPU ก็คือ เทคโนโลยีปัจจุบันพัฒนาไปไกลมาก
ปัจจุบันถือว่าเป็นเทคโนโลยีที่มีประสิทธิภาพด้านการทำงานสูงที่สุดในบรรดาทุกเทคโนโลยีในปัจจุบัน แต่จุดสังเกตก็คือประสิทธิภาพสูง
สูงสุด
แต่ออกกินไฟมากที่สุดในบรรดาทุกเทคโนโลยีด้วยเช่นกันนะครับสังเกตนะครับประสิทธิภาพมากแลกมาซึ่งพลังงานที่ใช้นะครับและความร้อนที่เกิดขึ้น
ในปัจจุบันการทำงานของ GPU ก็จะทำงานในรูปแบบของตัวเลขการบำรุงผลหรือ Computing Accelerator โดยจะมีเครื่องคอมพิวเตอร์หลักที่เรียกว่า Host ทำหน้าที่การควบคุม
หลังจากนั้นก็จะมีตัว GPU
ติดตั้งเป็น Device เสียบเป็นการ์ดอยู่ใน Host จำนวนก็แล้วแต่ความสามารถทางด้านฮาร์ดแวร์ที่จะบรรจุลงไปได้
ทีนี้ขั้นตอนในการทำงานก็คือจะมีโปรแกรมฝั่งโฮสต์และฝั่ง GPU
ต้องมีการสร้างโปรแกรมติดตั้งโปรแกรมไว้
และในการทำงานก่อนการทำงานโฮสต์จะทำหน้าที่โอนย้ายข้อมูลไปให้ GPU และติดตั้งโปรแกรมที่จะให้มัน Execute
หลังจากนั้นมันก็จะเกิดการทำงาน GPU ก็ทำงานโดยการประมวลผลกับ
เมมโมรี่ในตัว GPU ในการ์ดตัวนั้นใน Device Memory หลังประมวลผลเสร็จ Host ก็จะมา Transfer ผลลัพธ์ออกไปจาก Device Memory จากการ์ดจอดนั่นแหละ เอาไปใช้ในการทำงานต่อๆ ไป
ในการทำงานของ GPU ประสิทธิภาพสูง แต่มีข้อควรระวังเรื่อง Branch Divergent
ซึ่งเขาก็มีวิธีแก้ไขเพื่อให้การทำงานถูกต้องได้ แต่ก็แลกมาซึ่งประสิทธิภาพที่จะตกลงทั้งนั้น
นั่นคือข้อควรระวังเวลาเขียนโปรแกรม
พยายามหลีกเลี่ยงการทำให้เกิด Branch Divergence ให้มากที่สุด
เพื่อประสิทธิภาพที่สูงสุด
นั่นก็คือเรื่องของ GPU-based Computing Technology พอเห็นภาพแล้วนะครับ

เพียงแต่ว่าวันนี้จะเน้นย้ำให้เห็นถึงการประมวลผลด้านตัวเลขเป็นหลัก
และชี้ให้เห็นถึงประเด็นที่เขาจะทำให้เกิดประสิทธิภาพที่สูงขึ้นได้อย่างไร
เน้นในเรื่องของ Performance เป็นหลัก ชี้ให้เห็นของการเอา CPU Technology มาใช้ในการคำนวณหรือประมวลผลประสิทธิภาพสูง
เสร็จแล้วหัวใจสำคัญอันหนึ่งของวันนี้ก็คือเรื่องของความเข้าใจเกี่ยวกับสถาปัตยกรรมของการทำ Parallel Processing นั่นคือหัวข้อเรื่อง Parallel Processing Architecture
ว่ามันจะมีรูปแบบยังไงเดี๋ยวจะอธิบายให้ฟังและไอ้รูปแบบเนี้ยมันจะมีผลไปถึง
การทำงานของเทคโนโลยีตัวอื่นด้วยมันจะเป็นพื้นฐานเบื้องต้นคล้ายคล้ายกับเรา
ตั้งต้นปลูกพื้นให้ดีแล้วเดี๋ยวเทคโนโลยีอื่นอื่นมันก็จะมาต่อยอดได้
บาร์มเทคโนโลยีก็จะใช้รากฐานจาก Parallel Processing Architecture ตัวนี้ เดี๋ยวจะได้อธิบายต่อๆ ไป
ยกตัวอย่างเช่น GPU เสร็จแล้วเราก็จะมาเข้าสู่หัวข้อเรื่องของ High-end Computing ในการใช้ Processor หรือ CPU ให้เห็นภาพ

เทคโนโลยีของการประมวลผลประสิทธิภาพสูง
มันเริ่มต้นจากการถือกำเนิดของคอมพิวเตอร์
อันนี้ก็จะเป็นสไลด์ให้เห็นภาพประวัติแบบ
สรุปแบบย่อสุดยอด
ให้เห็นภาพว่าจริงๆแล้วที่นั่นคอมพิวเตอร์
มีมาตั้งแต่โบราณแล้วตั้งแต่ยุค 1940 กว่าๆนะครับ
แล้วก็เริ่มมีการนำเอาเครื่องจักรมาช่วยในการคำนวณประมวลผลคำนวณตัว
นะครับก็เริ่มมานะครับ
แล้วก็มีวิวัฒนาการขึ้นมาเรื่อยๆสมัยเดิม
มีเครื่องจักรมาช่วยเพื่อทำงานได้เร็วขึ้นพูดง่ายๆมีก็บุญแล้วนะครับเสร็จแล้วเขาก็เริ่มมีแนวคิดยุคแรกๆมันก็คือประมวลผลข้อมูลทีละตัว
แต่บังเอิญไอ้ทีละตัวนั้นน่ะมันทำได้ด้วยความเร็วที่สูงขึ้นกว่ามนุษย์ที่จะทำเท่านั้นเองนะครับทีละตัวก่อน
เสร็จแล้วหลังจากทำทีละตัวได้
ก็เริ่มมีแนวคิด
ทำไมไม่ทำทีละเป็นชุด
ไม่ทำทีละตัว
นั่นก็คือเริ่มต้นหลักการทำงานในลักษณะที่เรียกว่าเวคเตอร์ เวคเตอร์ก็คือการบำรุงผลข้อมูลทีละเป็นชุด
ตัวอย่างง่ายๆ ถ้าเรียนเรื่องของการเขียนโปรแกรมมาแล้ว
นึกถึงภาพ
ถ้าประมวลผลตัวเลขทีละตัว
ก็คือเวลาเราประกาศเขียนโปรแกรมเป็นตัวแปรเดี่ยวๆ ทีละตัว
เคยเขียนโปรแกรมใช่ไหมครับ ก็ประมวลผลแล้วเนี่ย แล้วดินแคลเป็น x เป็น y ก็บวกรบคุณหัน x y ทีละตัว
ทีละตัว แต่ถ้าเป็นเวคเตอร์
เปรียบเทียบให้เห็นภาพง่ายๆ
ในมุมมองของโปรแกรมเมอร์ก็คือ กำหนดข้อมูลเป็น a เลย
ถูกไหมครับแล้วก็ประมวลผลกับชุดแอร์เรทนั้น แต่ความแตกต่างก็คือถ้าเป็นการประมวลทีละชุด
เช่นโปรแกรมธรรมดาก็คือเราประมวลผลหนึ่งชุดอาจจะต้องใช้คำสั่งหลายคำสั่งถูกไหมฮะถูกไหมฮะ
แต่ถ้าเกิดเป็นแบบเวคเตอร์
คำสั่งเดียวสามารถประมวลผลกับข้อมูลแอร์เรย์หลายหลายตัวได้เลย
คำสั่งเดียวเห็นภาพยัง
ดังนั้นสมมุติมีข้อมูลอยู่ร้อยชุด
ถ้าเป็นแบบเดิมแบบดั้งเดิมคุณก็ต้องประมาณวันหลุด
แล้วก็ประมวลผลร้อยคำสั่ง
อันนี้เอาแบบสมมุติ
ประมวลผล 1 ทีก็คือ 1 คำสั่งนะ
แต่ถ้าเกิดเป็น Vector ให้เห็นภาพปิดเทียบง่ายๆว่ามันเร็วขึ้นยังไง ก็คือมีคำสั่งประมวลผลด้าน Vector สั่งคำสั่งเดียวเลยครับ
แล้วมันทำงานให้กับข้อมูล 100 ชุด
ไม่ต้องมานั่งถอดรหัสคำสั่ง
จำได้ใช่ไหมครับ ครั้งที่ผ่านมา
ไม่ต้องมานั่งถอดรหัสทีละคำสั่งคำสั่งเดียว
ถอดทีเดียว
แล้วไอ้กลไกการทำงานภายใต้การควบคุมของ Control Unit ทำให้เกิดการทำงานกับข้อมูลร้อยชุดนั้น
ซึ่งส่วนใหญ่ก็อยู่ในรูปแบบ Array ล่ะ ข้อมูลมันเรียงต่อกันไปเป็น Array นะครับ อยู่ในหน่วยความจำนั่นแหละ แล้วก็ทำทีเดียวเลย
ไม่ต้องมานั่งถอดรหัสคำสั่งทีละคำสั่งทีละคำสั่งไป
เห็นภาพไหมครับ ความเร็วมันก็ได้เร็วขึ้นนะครับ ต่างกันนะฮะ
นั่นคือวิวัฒนาการที่เกิดขึ้นมาก็โอ้โหสารพัดเลยครับเขาพยายามทำให้ไอ้คำสั่งประเภทเวคเตอร์นั้นน่ะมีความซับซ้อนขึ้นทำได้หลายอย่างมากขึ้นแทนที่จะบวก
เหมือนคูณเลขอย่างเดียวอาจจะทำเป็นโมเดลคณิตศาสตร์
เอาคูณก่อนแล้วค่อยเอามาบวกกันอะไรอย่างนี้ก็คิดค้นนะฮะแต่ถ้าสเปซิฟิกเกินไปที่ใช้มันก็จะจำกัดลงการใช้งานก็จะไม่หลากหลายถูกไหมฮะก็ถูกใช้งานเป็นการเฉพาะมากไป
แต่ก็เป็นวิวัฒนาการนะครับ เริ่มพัฒนาขึ้นมา
ต่อมาก็เริ่มบอก ในคำสั่งเดียวกับหลาย ๆ ข้อมูลหลาย ๆ ชุดเนี่ย ทำให้เกิดการทำงานแบบขนานได้ไหม
เดี๋ยวจะได้พูดถึงเกิดการทำงานแบบ SIMD Single Instruction Multiple Data ขึ้นมาในยุค 80 และเดี๋ยวจะได้พูดถึงเรื่องของ Architecture
นะครับไอซิมดีตัวนี้ก็จะอยู่ในหนึ่งอัคคิเชคเจอร์
แรกแรกก็ทำให้เกิดการประมวลผลแบบขนานจำนวนเพิ่มขึ้นแต่ยังไม่มากนัก
ต่อมาความต้องการประมวลผลความเร็วเพิ่มขึ้นแน่นอนหลักการเดิมครับ
ทำการประมวลผลแบบขนานให้จำนวนมากขึ้นมากขึ้นปริมาณมากมากเลยของเดิมเนี่ย
การประมงขนตัวเลขแบบขนานกันอาจจะทำอยู่ในระดับหลักสิบหรือหลักร้อย
หน่วยทำงานวงจรเนี่ยนะครับมีอยู่หลักสิบหลักร้อยพาราเลลแต่เขาก็เพิ่มจำนวนขึ้น
เพิ่มขึ้นเรื่อยเรื่อยเทคโนโลยีมันก็พัฒนาขึ้นไปเรื่อยเรื่อยเพิ่มจำนวนได้สะดวกขึ้นจนไปถึงหลักพันหลักหมื่นบางทีอาจจะกระโดดหลักแสนด้วย
เกิดเป็นลักษณะที่เรียกว่า MPP MPP
มันย่อมาจาก Massively Parallel Processing Massive แปลว่าปริมาณมากหรือจำนวนมาก
เห็นไหมครับ Parallel Processing ก็คือการประมวลผลแบบขนาน การประมวลผลแบบขนานแบบมีปริมาณมาก
มีหน่วยประมวลผลหรือวงจรประมวลผลจำนวนมากมาก
ทำงานขนาดกัน
สมัยก่อนแม้สีก็มากมากก็ตัวเลขก็ขึ้นหลักพันหลักหมื่นแน่นอนครับเมื่อวันเวลาเปลี่ยนไปเทคนิคพัฒนาขึ้นคำว่าปริมาณมากก็เพิ่มขึ้นเพิ่มขึ้นเรื่อยเรื่อยนะครับตาม
นะครับยุคแรกแรกคำว่าปริมาณมากก็อาจจะเพียงแค่หลักสิบหลักร้อยต่อมาเทคนิคผ่านไปวันเวลาผ่านไป
คำว่าปริมาณมากมันก็จะเพิ่มจำนวนมากขึ้น
เพราะฉะนั้นเวลาเราพูดถึงจำนวนหรือเกณฑ์อ้างอิงต่างๆ โดยช่วยยิ่งทางด้านเทคโนโลยี
กรุณาดูจังหวะเวลาด้วย ณ เวลานั้น ๆ อาจจะบอกว่า เฮ้ย เนี่ยมากแล้ว
เร็วแล้ว
แต่พอเวลาผ่านไป ตรงนั้นจะกลายเป็นของเด็ก ๆ เลย
กลายเป็นน้อยในอีกยุคนึง
อันนี้ชี้ให้เห็นนะครับ
ดังนั้นเวลาพูดถึงความเร็วในการประมวลผล
พูดถึงจำนวนในการทำงานพร้อมกัน
พาราแล็กซ์ Processing ดูเทคโนโลยี ดูวันเวลายุคสมัยของการทำงานด้วย
ต่อมาก็พัฒนาขึ้นมาเป็นหลาย ๆ เครื่อง
เอาหลาย ๆ เครื่องมาทำงานร่วมกันในลักษณะที่เรียกว่า Cluster
ในยุคปี 90 หลายเครื่องเอามาทำงานร่วมกัน
ต่อมาก็พอขึ้นปี 2000 เป็นต้นมาเทคนิคการผลิตชิปดีขึ้น ก็จับไอหลายหน่วยประมวลผลลงไปในชิปเดียวกัน เป็นลักษณะของมันติดคออย่างที่เคยอธิบายไป
ในยุคแรก ๆ การประมวลผลความเร็วสูง
เราจะเรียกคอมพิวเตอร์ที่มีความสามารถด้านการประมวลผลความเร็วสูงว่าซุปเปอร์คอมพิวเตอร์
ดังนั้นซุปเปอร์คอมพิวเตอร์ก็จะเป็นคอมพิวเตอร์ที่สามารถคำนวณตัวเลขหรือประมวลผลได้ด้วยความเร็วสูงนั่นเอง
และแน่นอนยุคแรกๆ คอมพิวเตอร์พวกนี้มันก็จะมีขนาดใหญ่
อินไฟล์เยอะก็จะต้องมีติดตั้งอยู่ในศูนย์คอมพิวเตอร์ถูกไหมฮะ
เป็นศูนย์คอมพิวเตอร์ใหญ่เลยใหญ่เล็กก็แล้วแต่กินไฟมากต่อมาเทคโนโลยีมันเปลี่ยนไปเปลี่ยนไปก็คือพัฒนาให้เล็กลงทำงานได้เร็วขึ้น
ซูเปอร์คอมพิวเตอร์ทำงานได้เร็วขึ้นเรื่อยเรื่อยมีขนาดเล็กลงเล็กลงจน
อ๋อราคาถูกลงด้วย
จนเริ่มเข้ามาใกล้ตัวคนธรรมดาอย่างพวกเรามากขึ้น
ยกตัวอย่างเช่นการนำของการ์ดจอแล้วก็พัฒนาไปว่าเดี๋ยวจะพูดถึงครั้งหน้าเรื่องของเทคโนโลยีของจีพียูเรื่องการ์ดจออีกทีหนึ่งนะครับนั่นคือตัวอย่างที่เห็นได้ชัดความสามารถในการประมวลผล
ของเครื่องคอมพิวเตอร์ส่วนบุคคลที่เราเรียกว่าพีซีก็เริ่มมี

อย่างนี้เป็นต้น
การทำงานยังเกิดขึ้นที่ฮาร์ดแวร์เสมอ
ย้ำนะครับพอเดี๋ยวตัวนี้เดี๋ยวเทคโนโลยีต่างๆ จะเริ่มชี้ให้เห็นต่อไป
เสร็จแล้วฮาร์ดแวร์อาจจะ
สั่งการหรือควบคุมโดยใช้ซอฟต์แวร์ผ่าน
รหัสคำสั่ง
หรือผ่านรูปแบบอื่นๆ
ขึ้นอยู่กับเทคโนโลยีที่เดี๋ยวเราจะได้เรียนกันต่อไป
ดังนั้นวันนี้คงพอมองเห็นภาพของ CPU-based Computing แล้วนะครับ จริงๆก็คือการทำให้ CPU หรือคอมพิวเตอร์
เทคโนโลยีคอมพิวเตอร์แบบเดิมๆนั่นแหละ เกิดการทำงานความเร็วสูงได้
และก็เป็นเทคโนโลยีที่เกิดขึ้นมาในยุคแรกๆ เป็นสร้างเป็นซูเปอร์คอมพิวเตอร์ขึ้นมา
แต่พอเวลาเปลี่ยนไป เดี๋ยวเทคโนโลยีอื่นก็จะเริ่มมา ซึ่งเดี๋ยวครั้งหน้าเราก็จะได้เรียนเรื่องของเทคโนโลยีอื่นๆต่อไป

NLP with Deep Learning — ชีตสรุป (ไทย) Weeks 1–4 · สูตร + ตัวอย่างแทนค่า · เลือกข้อที่ถูก / จับข้อที่ผิด

W1 · Word Representation

  • One-Hot: sparse, ตั้งฉาก (orthogonal) → วัด similarity ไม่ได้. WordNet: ทำมือ, ตกยุค/ขาดคำใหม่. SVD/LSA: factorize co-occurrence → dense; ช้า O(N³), เพิ่มคำใหม่ยาก.
  • Co-occurrence Matrix: นับคำที่อยู่ใกล้กันใน window; symmetric, ใหญ่, sparse.

W1 · PMI / PPMI

PMI(w,c) = log₂ [ P(w,c) / (P(w)·P(c)) ] PPMI = max(PMI, 0)

PMI bug: ไม่เคยคู่กัน → log(0) = −∞. PPMI ตัดค่าลบเป็น 0.

ตัวอย่าง P(w,c)=0.1, P(w)=0.2, P(c)=0.25 → 0.1/0.05=2 → PMI=log₂2=1.0

W1 · Word2Vec

  • Skip-gram: คำกลาง → เดา context (ดีกับคำหายาก).
  • CBOW: context → เดาคำกลาง (เร็ว, smooth).
  • Objective: maximize Σ log P(context | center), softmax ทั้ง vocab; ใช้ negative sampling เลี่ยง softmax เต็ม.

W1 · SentencePiece / Loss

  • SentencePiece: มองข้อความเป็น raw stream, ช่องว่าง = ▁ → ภาษาอิสระ, ย้อนกลับได้, เหมาะกับ ภาษาไทย (ไม่มีเว้นวรรค).
  • CrossEntropyLoss = LogSoftmax + NLLLoss. CE รับ logits ดิบ; NLLLoss รับ log-probabilities.

W2 · ก่อน RNN / RNN พื้นฐาน

  • N-gram: sparsity + เก็บตารางใหญ่, บริบทคงที่. Fixed-window NLM: ไม่แชร์น้ำหนัก, ขนาดคงที่, ไม่มีบริบทยาว.
  • RNN: hₜ=tanh(W_hh·hₜ₋₁ + W_xh·xₜ + b). แชร์ W ชุดเดียวทุก timestep → รับความยาวเท่าไหร่ก็ได้, พารามิเตอร์น้อย.
  • GRU: reset + update gate; พารามิเตอร์น้อยกว่า LSTM, ไม่มี cell state แยก.

W2 · Init · ชนิดงาน · PPL

  • Xavier/Glorot → tanh/sigmoid (var=2/(n_in+n_out)). He/Kaiming → ReLU (var=2/n_in).
  • Many-to-one: classification. Many-to-many: tagging / seq2seq. One-to-many: captioning.
Perplexity = e^J (J = avg cross-entropy loss)
ตัวอย่าง loss J=2.0 → PPL=e²≈7.39. PPL=k คืองงเท่าเดามั่วจาก k คำ. ยิ่งต่ำยิ่งดี

W2 · BPTT · Gradients

  • BPTT: คลี่ตามเวลาแล้ว backprop; คูณ W ซ้ำ ทำให้ vanishing (‖W‖<1) หรือ exploding (‖W‖>1).
  • Exploding → Gradient clipping: ถ้า ‖g‖>τ, g←g·τ/‖g‖.
  • Vanishing → LSTM/GRU gates + cell state / skip connection.

W2 · LSTM Gates 3 ข้อ

forget=σ · input=σ · output=σ · candidate g=tanh

cₜ = fₜ⊙cₜ₋₁ + iₜ⊙gₜ hₜ = oₜ⊙tanh(cₜ)
  • Cell state cₜ = "ทางด่วน gradient": อัปเดตด้วยการ บวก (ไม่ใช่คูณเมทริกซ์) → gradient ไหลไกลได้.
  • Forget=ทิ้งจาก cₜ₋₁; Input=เขียนอะไรใหม่; Output=เปิดอะไรออกเป็น hₜ.

W2 · BiRNN · Teacher Forcing

  • Bidirectional RNN: concat forward+backward → ต้องเห็นทั้งประโยค; ใช้ generation แบบ causal/เรียลไทม์ไม่ได้.
  • Teacher forcing: ป้อน ground-truth ตอนเทรน. Exposure bias: ตอน test โมเดลเห็นoutput ตัวเอง → train/test mismatch, error สะสม.

W3 · BLEU

BLEU = BP · exp( Σ wₙ·ln pₙ ) BP = 1 ถ้า c>r, มิฉะนั้น exp(1 − r/c)

pₙ = clipped precision (นับ n-gram ได้ไม่เกินที่ reference มี → กัน "the the the"). c=ความยาว candidate, r=reference. เน้น precision (แปล). ไม่เข้าใจความหมาย.

ตัวอย่าง c=8, r=10 → BP=exp(1−10/8)=exp(−0.25)≈0.779

W3 · ROUGE · Decoding

  • ROUGE: เน้น recall (สรุปข้อความ). ROUGE-L: ใช้ Longest Common Subsequence (จับลำดับ ไม่ต้องติดกัน).
  • Greedy: argmax ทุกก้าว (สายตาสั้น). Beam search: เก็บ top-k เส้นทาง.
  • Length normalization: หารด้วย lengthᵃ กัน beam ชอบประโยคสั้น.

W3 · Temperature · Sampling

pᵢ = softmax(zᵢ / T)

T<1 คม/ซ้ำเดิม (T→0 ≈ greedy); T>1 แบน/สุ่ม/สร้างสรรค์.

Scheduled sampling (teacher-forcing ratio): ค่อยๆป้อน prediction ตัวเองตอนเทรน → ลด exposure bias.

W3 · Attention (ทำไม + math)

  • Info bottleneck: context vector ตัวเดียวบรรจุประโยคยาวไม่พอ → attention ให้ decoder มองทุก encoder state.
eₜᵢ = score(sₜ, hᵢ); αₜ = softmax(eₜ) contextₜ = Σᵢ αₜᵢ·hᵢ

Q/K/V (seq2seq): Query = decoder state; Key/Value = encoder states.

W4 · ทำไมทิ้ง RNN / CNN

  • RNN sequential trap: ขนานตามเวลาไม่ได้; ระยะทางไกล = O(n).
  • CNN: receptive field จำกัด, ต้องหลายชั้นกว่าจะครอบคลุมประโยคยาว.
  • Transformer: path length O(1), ขนานได้; ต้นทุน O(T²) attention.

W4 · Self-Attention + √dₖ

Attn = softmax( QKᵀ / √dₖ ) · V

Q,K,V = projection จาก input เดียวกัน. หาร √dₖ: dₖ ใหญ่ → dot product variance โต → softmax อิ่มตัว; scaling ดึง variance ≈1 ให้ gradient ดี.

W4 · Positional Encoding

PE(pos,2i)=sin(pos/10000^{2i/d}) PE(pos,2i+1)=cos(pos/10000^{2i/d})

บวกเข้ากับ word embedding (attention ไม่มี sense ของลำดับ). อยู่ [−1,1]; แต่ละมิติความถี่ต่าง → เรียน relative position ได้.

W4 · Multi-Head · Residual · Norm

  • Multi-head: รัน attention h หัวขนาน; แต่ละหัว dₖ=d_model/h (512/8=64); concat → W_O. ต้นทุน ≈ single head.
  • Residual: x + Sublayer(x) → gradient ไหลลื่น.
  • LayerNorm normalize ข้าม features ต่อ token → ไม่ขึ้นกับ batch, เหมาะ NLP. BatchNorm normalize ข้าม batch (ไม่ดีกับ NLP).

W4 · FFN · Params · Complexity

  • FFN: position-wise W₂·ReLU(W₁x+b₁)+b₂, มัก d_ff=4·d_model. Shape invariance: shape output = input.
  • Attention params / layer = 4·d_model² (Wq,Wk,Wv,Wo). LLaMA-7B d=4096 → 4·4096²≈67.1M/layer.
  • Memory complexity O(T²) (attention matrix T×T).
หน้า 1 / 2 · กรอบแดง = ออกหนัก · ~18 ข้อเป็นการคำนวณ แสดงวิธีคิดเพื่อคะแนนบางส่วน

NLP with Deep Learning — ชีตสรุป (ไทย) Weeks 5–7 · KV Cache ⭐ · BERT · GPT · คู่ที่สับสน

W5 · Causal Mask · Train vs Infer

  • Causal / look-ahead mask: ใส่ −∞ ในสามเหลี่ยมบน ก่อน softmax → token t มองได้แค่ ≤ t (ห้ามเห็นอนาคต).
  • Training: ขนานทั้งประโยค, teacher forcing, ทุกตำแหน่งพร้อมกัน. Inference: autoregressive ทีละคำ, ป้อน output กลับ → ช้า.
  • Cross-attention: Q จาก decoder, K/V จาก encoder (self-attn: มาจากที่เดียวกัน).

⭐ W5 · KV Cache 5 ข้อ

  • แนวคิด: K,V ของ token เก่าไม่เปลี่ยน → cache ไว้, คำนวณแค่ kₜ,vₜ ของ token ใหม่. เลี่ยงคำนวณ prefix ซ้ำ.
  • ต้นทุน: ต่อ token O(t²)→O(t) (O(N²) overall).
  • GEMM→GEMV: Qₜ เหลือแถวเดียว (B×1×dₖ) → matrix-vector.
  • Compute-bound → Memory-bound: arithmetic intensity = FLOPs/Bytes ลด; คอขวดเป็นการขน K/V ผ่าน memory bus.
KV bytes = 2·precision·n_layers·d_model·n_ctx·B

(×2 = K และ V). แบบ lab: 2·B·seq·n_kv_heads·head_dim·n_layers·bytes.

ตัวอย่าง (lab) B=4, seq=2048, head_dim=128, layers=32, FP16(2B):
MHA 32 heads → 2·4·2048·32·128·32·2 /1024² = 4096 MB.
GQA 8 heads → 1024 MB (เล็กลง 4 เท่า).

W5 · VRAM Planning

Static = params × bytes

LLaMA-7B FP16: 7e9×2 ≈ 14 GB locked. VRAM รวม = static weights + KV cache. context ยาว (n_ctx) & batch ใหญ่ (B) พอง cache → CUDA OOM.

W5 · Decoding: Top-k / Top-p

  • Top-k: เก็บ k token prob สูงสุด (จำนวนคงที่).
  • Top-p / nucleus: เก็บเซตเล็กสุดที่ prob สะสม ≥ p (ปรับตาม).
  • ลำดับกรอง: temperature → top-k → top-p → softmax → sample.

W6 · BERT: การ Pretrain

  • Self-supervised: label มาจากข้อมูลเอง (pretext task) ไม่ต้อง label คน. Transfer learning: pretrain ครั้งเดียว → fine-tune หลายงาน.
  • Input embedding = Token + Segment + Position (บวกกัน).
  • [CLS]: token แรก; pooled output ใช้ classification. [SEP]: คั่นสองประโยค.

W6 · MLM · NSP

  • MLM — กฎ 15%: mask 15% ของ WordPiece tokens. ในนั้น: 80% → [MASK], 10% → คำสุ่ม, 10% → คงเดิม (ให้ fine-tune ที่ไม่มี [MASK] ไม่ตกใจ).
  • <15% signal อ่อน; >15% บริบทหาย.
  • NSP: binary IsNext / NotNext — B ตามหลัง A ไหม? (ใช้ [CLS]).
  • MLM = บริบท สองทิศทาง.

W6 · Fine-tune vs Feature-extract

  • Fine-tuning: อัปเดตทุกน้ำหนัก (BERT default).
  • Feature extraction: freeze, ใช้ embedding เป็น feature (แนว ELMo).
  • BERT vs ELMo: BERT = Transformer สองทิศทางลึก; ELMo = concat LSTM สองตัวแยกกัน.

W6 · BERT variants

โมเดลจุดเปลี่ยนสำคัญ
RoBERTaตัด NSP, dynamic masking, data เยอะ/เทรนนาน/batch ใหญ่
DeBERTadisentangled attention: แยก content + relative-position
SpanBERTmask เป็น span ต่อเนื่อง + span-boundary objective

W6 · QA · HF · Probing

  • Extractive QA (SQuAD): ทำนาย start และ end ของ span คำตอบในบริบท.
  • HF pipeline: ระดับสูงบรรทัดเดียว. AutoModel: ได้ raw hidden states, ต่อ head เอง ([CLS] = last_hidden_state[:,0,:]).
  • BERTology / probing: วิเคราะห์ attention heads & layers → ชั้นต่ำ≈syntax, ชั้นสูง≈semantics.

W7 · CLM · GPT evolution

  • CLM: ทำนาย token ถัดไป, causal mask. Signal density: ทุก token เป็น label (dense) vs MLM ~15% (sparse).
  • Loss = เลื่อน logits/labels 1 ช่อง: logits[:-1] vs labels[1:].
  • GPT-1→2→3: ↑scale → zero/few-shot & in-context learning (เรียนจาก prompt ไม่อัปเดตน้ำหนัก).
  • Open weights (LLaMA) vs closed (GPT-4 API).

W7 · RoPE · RMSNorm · SwiGLU

  • RoPE: หมุน Q,K ด้วยมุมตามตำแหน่ง → encode relative position, extrapolate ดี.
RMSNorm: y = x/√(mean(x²)+ε) · γ

ไม่ลบ mean, ไม่มี bias → เบากว่า LayerNorm.

SwiGLU = (SiLU(xW₁) ⊙ xW₃)·W₂

SiLU(x)=x·σ(x); 3 matrices, params = 3·in·hidden.

W7 · MQA / GQA

  • MHA: ทุก query head มี K,V ของตัวเอง.
  • MQA: KV head เดียวร่วมกัน → cache เล็กสุด, quality ตกเล็กน้อย.
  • GQA: query แบ่งกลุ่ม แชร์ KV head → สายกลาง (LLaMA-2/3).
  • ทั้งคู่ ลด KV cache ∝ n_kv_heads (เช่น 32→8 heads = ÷4).

W7 · Scaling Laws · ICL

  • Kaplan (2020): ขยาย โมเดลเร็วกว่า data.
  • Chinchilla (2022): ขยายโมเดล & data เท่าๆกัน — rule of thumb ~20 tokens/param (70B ⇒ ~1.4T tokens).
  • In-context learning: induction heads / function vectors ตอน inference. Context extension ด้วย RoPE scaling; omnimodal = text+image+audio.

  • "WordPiece รวมคู่ บ่อยสุด" → นั่นคือ BPE.
  • "Clipping แก้ vanishing" → แก้ exploding.
  • "Transformer ใช้ BatchNorm" → LayerNorm.
  • "Bahdanau ใช้ dot-product" → additive (Luong=dot).
  • "BLEU เน้น recall" → precision (ROUGE=recall).
  • "MLM mask 50%" → 15% (80/10/10).
  • "GQA เพิ่ม KV cache" → ลด.
  • "RMSNorm ลบค่าเฉลี่ย" → ไม่ลบ.
  • "Kaplan = 20 tokens/param" → Chinchilla.
  • "CrossEntropy รับ log-probs" → รับ logits.

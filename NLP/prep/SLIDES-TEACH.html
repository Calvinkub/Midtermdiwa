ทำไม One-Hot ไม่พอ?

One-Hot

เวกเตอร์ยาวเท่า vocab มี 1 ตัวเดียว → ตั้งฉากกันหมด วัดความเหมือนไม่ได้ (cat กับ dog ห่างเท่า cat กับ car)

WordNet

พจนานุกรมทำมือ → ตกยุค, ขาดคำใหม่/นัยความหมาย, ต้องใช้แรงคนดูแล

  • Co-occurrence Matrix: นับว่าคำไหนอยู่ใกล้กันในหน้าต่าง (window) → เมทริกซ์ใหญ่มากและ sparse
  • SVD / LSA: แยกเมทริกซ์ (factorize) บีบให้เหลือมิติน้อยแบบ dense — แต่ช้า O(n²·m) และเพิ่มคำใหม่ยาก
แนวคิดหลัก

"You shall know a word by the company it keeps" — ความหมายของคำ = บริบทที่มันปรากฏ (Distributional Hypothesis)

W1 · Co-occurrence · PMI
PMI / PPMI — วัดว่าสองคำ "คู่กันผิดปกติ" แค่ไหน
PMI(w,c) = log₂ [ P(w,c) / ( P(w)·P(c) ) ]
  • P(w,c) = โอกาสที่คู่นี้ปรากฏด้วยกัน · P(w),P(c) = โอกาสแต่ละคำ · >0 = คู่กันบ่อยกว่าบังเอิญ
  • PMI Bug: ถ้าไม่เคยคู่กันเลย P(w,c)=0 → log(0) = −∞
PPMI(w,c) = max( PMI(w,c), 0 ) ← ตัดค่าลบทิ้ง
ตัวอย่างคำนวณ

P(w,c)=0.1, P(w)=0.2, P(c)=0.25 → 0.1 / (0.2×0.25) = 0.1/0.05 = 2 → PMI = log₂2 = 1.0 → PPMI = 1.0

Word2Vec: เดาบริบท → ได้เวกเตอร์หนาแน่น

Skip-gram

ให้คำกลาง → เดาบริบทรอบๆ · ดีกับคำหายาก · ช้ากว่า

CBOW

ให้บริบท → เดาคำกลาง · เร็วกว่า · smooth กว่า

Objective (Skip-gram): maximize Σ_t Σ_{−m≤j≤m, j≠0} log P( w_{t+j} | w_t )
  • P(o|c) = softmax ของ dot-product เวกเตอร์ → หาร normalize ทั้ง vocab (แพง)
  • Negative Sampling: แทนที่จะ softmax ทั้ง vocab → สุ่มคำ "ผิด" ไม่กี่ตัวมาเทียบ → เร็วขึ้นมาก

SentencePiece

มองข้อความเป็น สตรีมดิบ เข้ารหัสช่องว่างเป็น ▁ → ภาษาอิสระ, ย้อนกลับได้

NLL vs CrossEntropy

CrossEntropy = LogSoftmax + NLLLoss

W2 · BPTT · Vanishing/Exploding
gradient หาย vs ระเบิด — แก้คนละทาง
  • BPTT: คลี่ RNN ตามเวลาแล้ว backprop → ต้องคูณ W ซ้ำๆหลายครั้ง
  • Vanishing (‖W‖<1): gradient เล็กลงจนหาย → เรียนบริบทไกลไม่ได้ → แก้ด้วย LSTM/GRU gates + skip connection
  • Exploding (‖W‖>1): gradient โตระเบิด → แก้ด้วย Gradient Clipping
Gradient Clipping: ถ้า ‖g‖ > τ → g ← g · ( τ / ‖g‖ )
กับดักข้อสอบ

"Gradient clipping แก้ปัญหา vanishing gradient" = ผิด → clipping แก้ exploding เท่านั้น (vanishing ต้องใช้ gate/skip)

W2 · LSTM Gates ออก 3 ข้อ
LSTM: 3 ประตู + ทางด่วน gradient
  • Forget f = σ: ทิ้งอะไรจาก cell เก่า
  • Input i = σ: รับข้อมูลใหม่แค่ไหน
  • Candidate g = tanh: ข้อมูลใหม่คืออะไร
  • Output o = σ: เปิดอะไรออกเป็น hₜ
cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ gₜ
hₜ = oₜ ⊙ tanh(cₜ)
หัวใจ: Cell State cₜ

"ทางด่วน gradient" — cell state ถูกอัปเดตด้วยการ บวก (+) ไม่ใช่คูณเมทริกซ์ → gradient ไหลข้าม timestep ไกลๆได้โดยไม่หาย (คล้าย residual connection)

Seq2Seq & Attention
วัดผลการแปล/สรุป และจุดกำเนิดของ Attention ที่ปฏิวัติวงการ
BLEU · ROUGE · Beam Search · Attention · Bahdanau vs Luong
W3 · BLEU คำนวณ
BLEU — วัดคุณภาพการแปล (เน้น precision)
BLEU = BP · exp( Σₙ wₙ · ln pₙ )
  • pₙ = clipped precision: นับ n-gram ตรงกับ reference ได้ไม่เกินจำนวนที่มีจริง → กัน "the the the the"
  • Brevity Penalty (BP): ลงโทษคำแปลสั้นเกินไป
BP = 1 ถ้า c > r , มิฉะนั้น BP = exp( 1 − r/c ) (c=ความยาวคำแปล, r=reference)
ตัวอย่าง BP

คำแปลยาว c=8, reference r=10 → c<r → BP = exp(1 − 10/8) = exp(−0.25) ≈ 0.779 · จุดอ่อน: BLEU ไม่เข้าใจความหมาย ("huge" vs "massive" = 0)

W3 · ROUGE · Decoding
ROUGE-L + วิธีเลือกคำถัดไป

ROUGE (สรุปข้อความ)

เน้น recall (ตรงข้าม BLEU) · ROUGE-L ใช้ LCS (Longest Common Subsequence) จับลำดับ ไม่ต้องติดกัน

Greedy vs Beam

Greedy: เลือก argmax ทุกก้าว (สายตาสั้น) · Beam Search: เก็บ top-k เส้นทางไว้พร้อมกัน

  • Length Normalization: หารคะแนนด้วย (ความยาว)^α → กัน beam ชอบประโยคสั้นเกินไป
  • จำ: BLEU=precision/แปล · ROUGE=recall/สรุป
W3 · Temperature · Scheduled Sampling
Temperature คุมความ "มั่ว" ของโมเดล
pᵢ = softmax( zᵢ / T )
  • T < 1: distribution คมขึ้น → มั่นใจ/ซ้ำเดิม (T→0 ≈ greedy argmax)
  • T > 1: distribution แบนลง → สุ่ม/สร้างสรรค์/หลากหลาย
Scheduled Sampling (Teacher Forcing Ratio)

ค่อยๆลดการป้อนคำตอบจริง แล้วเพิ่มการป้อนคำที่โมเดลทำนายเองระหว่างเทรน → ลด exposure bias ให้โมเดลชินกับ input ตอน inference

W3 · Information Bottleneck → Attention
ทำไมต้องมี Attention?
  • Information Bottleneck: seq2seq เดิมบีบทั้งประโยคเป็น context vector ตัวเดียว → ประโยคยาวข้อมูลหาย
  • Attention: ให้ decoder "มองย้อน" ไปที่ทุก hidden state ของ encoder แล้วถ่วงน้ำหนักเอง
eₜᵢ = score(sₜ, hᵢ)
αₜ = softmax(eₜ)
contextₜ = Σᵢ αₜᵢ · hᵢ

Q / K / V (ใน seq2seq)

Query = decoder state (สₜ)
Key/Value = encoder states (hᵢ)
→ "ถามว่าตอนนี้ควรสนใจคำไหน"

RNN — Sequential Trap

ต้องคำนวณทีละ timestep → ขนานไม่ได้ · ระยะทางระหว่างคำไกล = O(n) → บริบทไกลจางหาย

CNN — Receptive Field

เห็นได้แค่หน้าต่างเล็กๆ ต้องซ้อนหลายชั้นกว่าจะครอบคลุมประโยคยาว

Transformer แก้ยังไง

Self-attention เชื่อมทุกคำถึงกันโดยตรง → ระยะทาง = O(1) · คำนวณขนานทั้งประโยคพร้อมกัน · แลกมาด้วยต้นทุน O(T²)

W4 · Self-Attention · Scaled Dot-Product
หัวใจ Transformer + ทำไมต้องหาร √dₖ
Attention(Q,K,V) = softmax( Q·Kᵀ / √dₖ ) · V
  • Q, K, V = projection จาก input ตัวเดียวกัน (self) · QKᵀ = คะแนนความเข้ากันของทุกคู่คำ
  • softmax → น้ำหนัก (%) ว่าแต่ละคำควรสนใจคำอื่นแค่ไหน แล้วเอาไปถ่วง V
ทำไมหาร √dₖ

เมื่อ dₖ ใหญ่ dot-product มี variance โตตาม dₖ → ค่าใหญ่มากทำให้ softmax อิ่มตัว (gradient ≈ 0) · หาร √dₖ ดึง variance กลับมา ≈ 1 → เทรนได้ลื่น

W4 · Positional Encoding คำนวณ
ฉีด "ลำดับ" กลับเข้าไป (sin/cos)
  • Self-attention ไม่มีแนวคิดเรื่องลำดับ → ต้องบวก positional encoding เข้ากับ word embedding
PE(pos, 2i)  = sin( pos / 10000^(2i/d) )
PE(pos, 2i+1) = cos( pos / 10000^(2i/d) )

ทำไม sin/cos

ค่าถูกบีบใน [−1,1] · แต่ละมิติมีความถี่ต่างกัน → โมเดลเรียนตำแหน่งสัมพัทธ์ได้ · ขยายไป seq ยาวกว่าตอนเทรนได้

FinalInput = WordEmbedding + PositionalEncoding
W4 · Multi-Head · Residual · LayerNorm
ประกอบร่าง Encoder Block
  • Multi-Head: รัน attention h หัวขนานกัน แต่ละหัวมองคนละแบบ · dₖ = d_model / h (512/8 = 64) แล้ว concat → คูณ Wₒ
  • Residual: x + Sublayer(x) → gradient ไหลลื่น ไม่หาย
LayerNorm vs BatchNorm (ออกบ่อย!)

LayerNorm normalize ข้าม features ของแต่ละ token → ไม่ขึ้นกับ batch size เหมาะกับ NLP ที่ประโยคยาวไม่เท่ากัน · BatchNorm normalize ข้าม batch → ใช้กับ NLP ไม่ดี

W4 · FFN · Param Counting คำนวณ
Feed-Forward + นับพารามิเตอร์
  • FFN: W₂·ReLU(W₁x+b₁)+b₂ ทำแยกทีละตำแหน่ง (position-wise) · มักตั้ง d_ff = 4·d_model
  • Shape Invariance: shape output = shape input เสมอ → ต่อ block ซ้อนกันได้เรื่อยๆ
Attention params / layer = 4 · d_model² (Wq, Wk, Wv, Wo)
ตัวอย่าง + Complexity

LLaMA-7B d_model=4096 → 4·4096² ≈ 67.1M พารามิเตอร์ (แค่ attention ชั้นเดียว!) · Memory ของ attention = O(T²) (เมทริกซ์ T×T)

Query เหลือแค่ token เดียว (B×1×dₖ) → เปลี่ยนจากคูณเมทริกซ์-เมทริกซ์ (GEMM) เป็นเมทริกซ์-เวกเตอร์ (GEMV) · คอขวดย้ายจากการคำนวณ ไปเป็นการขนย้ายข้อมูล K/V ผ่าน memory bus

คำนวณหน่วยความจำ KV Cache
KV bytes = 2 · precision · n_layers · d_model · n_ctx · B   (×2 = เก็บทั้ง K และ V)
แบบใน Lab: 2 · B · seq · n_kv_heads · head_dim · n_layers · bytes
ตัวอย่างจาก Lab (B=4, seq=2048, head_dim=128, layers=32, FP16=2B)

Top-k vs Top-p

Top-k: เก็บ k ตัวที่ prob สูงสุด (จำนวนคงที่)
Top-p (nucleus): เก็บเซตเล็กสุดที่ prob สะสม ≥ p (ปรับตาม)

ลำดับการกรอง: temperature → top-k → top-p → softmax → sample (multinomial)
Top-p ยืดหยุ่นกว่า: distribution แบน→เก็บหลายตัว, distribution คม→เก็บน้อยตัว

RoPE

หมุน Q,K ด้วยมุมตามตำแหน่ง → เข้ารหัสตำแหน่งสัมพัทธ์ ขยาย context ได้ดี

RMSNorm

y = x / √(mean(x²)+ε) · γ
ไม่ลบค่าเฉลี่ย ไม่มี bias → เบา/เร็วกว่า LayerNorm

SwiGLU(x) = ( SiLU(x·W₁) ⊙ x·W₃ ) · W₂   → 3 เมทริกซ์, params = 3·in·hidden

W7 · MQA/GQA · Scaling Laws
ลด KV Cache + กฎการขยายขนาด
  • MHA: ทุก query head มี K,V ของตัวเอง · MQA: ใช้ KV head เดียวร่วมกัน (cache เล็กสุด) · GQA: query แบ่งกลุ่ม แชร์ KV head (ทางสายกลาง — LLaMA-2/3)

Kaplan vs Chinchilla (กับดัก!)

Kaplan (2020): ขยายโมเดลให้เร็วกว่า data · Chinchilla (2022): ขยายโมเดลกับ data เท่าๆกัน — rule of thumb ~20 tokens ต่อ 1 parameter (โมเดล 70B ต้องการ ~1.4T tokens)

W7 · In-Context Learning · Context Extension
กลไกเบื้องหลัง LLM ยุคใหม่
  • In-Context Learning: โมเดลจับ pattern จากตัวอย่างใน prompt แล้วทำตามได้ทันที (induction heads / function vectors) — ไม่มีการอัปเดตน้ำหนัก
  • Context Extension: ขยายความยาว context ที่รับได้ (เช่น RoPE scaling) ให้ยาวกว่าตอนเทรน
  • Omnimodal: รับ-สร้างได้หลายรูปแบบ (ข้อความ + ภาพ + เสียง) ในโมเดลเดียว

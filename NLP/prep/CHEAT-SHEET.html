NLP with Deep Learning — Midterm Cheat Sheet Weeks 1–4 · formulas + worked examples · pick the BEST / spot the WRONG

W1 · Word Representation

  • One-hot: sparse, orthogonal → no similarity. WordNet: manual, misses nuance/new words. SVD/LSA: factorize co-occurrence → dense; expensive, hard to add words.
  • Co-occurrence matrix: count words within window; symmetric, huge, sparse.

W1 · PMI / PPMI

PMI(w,c) = log₂ [ P(w,c) / (P(w)·P(c)) ] PPMI = max(PMI, 0)

PMI bug: never co-occur → log(0) = −∞. PPMI clips negatives to 0.

Ex. P(w,c)=0.1, P(w)=0.2, P(c)=0.25 → 0.1/(0.05)=2 → PMI=log₂2=1.0.

W1 · Word2Vec

  • Skip-gram: center → predict context (better for rare words).
  • CBOW: context → predict center (faster, smoother).
  • Objective: maximize Σ log P(context | center), softmax over vocab; use negative sampling to avoid full-vocab softmax.

W1 · SentencePiece / Loss

  • SentencePiece: treats raw text as a stream, encodes spaces as ▁ → language-agnostic, reversible, great for Thai (no word spaces).
  • CrossEntropyLoss = LogSoftmax + NLLLoss. CE takes raw logits; NLLLoss takes log-probabilities.

W2 · Before RNN / RNN basics

  • N-gram: sparsity + storage blow-up, fixed context. Fixed-window NLM: no weight sharing, fixed input size, no long context.
  • RNN: hₜ=tanh(W_hh·hₜ₋₁ + W_xh·xₜ + b). Same weights shared across all timesteps → handles variable length, fewer params.
  • GRU: reset + update gate; fewer params than LSTM, no separate cell state.

W2 · Init · Task shapes · PPL

  • Xavier/Glorot → tanh/sigmoid (var=2/(n_in+n_out)). He/Kaiming → ReLU (var=2/n_in).
  • Many-to-one: classification. Many-to-many: tagging / seq2seq. One-to-many: captioning.
Perplexity = e^J (J = avg cross-entropy loss)
Ex. loss J=2.0 → PPL=e²≈7.39. PPL k ⇒ as confused as guessing among k words. Lower = better.

W2 · BPTT · Gradients

  • BPTT: unroll through time, backprop; repeated ×W causes vanishing (‖W‖<1) or exploding (‖W‖>1) gradients.
  • Exploding → Gradient clipping: if ‖g‖>τ, g←g·τ/‖g‖.
  • Vanishing → LSTM/GRU gates + additive cell state / skip connections.

W2 · LSTM Gates 3Q

forget=σ · input=σ · output=σ · candidate g=tanh

cₜ = fₜ⊙cₜ₋₁ + iₜ⊙gₜ hₜ = oₜ⊙tanh(cₜ)
  • Cell state cₜ = "gradient superhighway": info updated by addition (not matrix mult) → gradients flow far.
  • Forget=what to drop from cₜ₋₁; Input=what new to write; Output=what to expose as hₜ.

W2 · BiRNN · Teacher Forcing

  • Bidirectional RNN: concat forward+backward states → needs the whole sequence; can't be used for causal/online generation.
  • Teacher forcing: feed ground-truth prev token in training (fast, stable). Exposure bias: at test the model sees its own outputs → train/test mismatch, errors compound.

W3 · BLEU

BLEU = BP · exp( Σ wₙ·ln pₙ ) BP = 1 if c>r, else exp(1 − r/c)

pₙ = clipped n-gram precision (count each n-gram at most as many times as in reference → stops "the the the"). c=candidate len, r=reference len. Precision-oriented (MT). No semantics: "huge"≠"massive".

Ex. c=8, r=10 → BP=exp(1−10/8)=exp(−0.25)≈0.779.

W3 · ROUGE · Decoding

  • ROUGE: recall-oriented (summarization). ROUGE-L: based on Longest Common Subsequence (order-aware, no fixed n).
  • Greedy: argmax each step (myopic). Beam search: keep top-k hypotheses.
  • Length normalization: divide score by lengthᵃ so beam doesn't favor short outputs.

W3 · Temperature · Sched. Sampling

pᵢ = softmax(zᵢ / T)

T<1 sharper/greedier; T>1 flatter/random; T→0 ≈ argmax.

Scheduled sampling (teacher-forcing ratio): gradually feed model's own predictions during training to reduce exposure bias.

W3 · Attention (why + math)

  • Info bottleneck: a single fixed context vector can't hold a long sentence → attention lets decoder look at all encoder states.
eₜᵢ = score(sₜ, hᵢ); αₜ = softmax(eₜ) contextₜ = Σᵢ αₜᵢ·hᵢ

Q/K/V in seq2seq: Query = decoder state; Keys/Values = encoder states.

W4 · Why drop RNN / CNN

  • RNN sequential trap: can't parallelize over time; long dependency path = O(n).
  • CNN: limited receptive field, needs many layers for long range.
  • Transformer: path length O(1), fully parallel; cost = O(T²) attention.

W4 · Self-Attention + √dₖ

Attn = softmax( QKᵀ / √dₖ ) · V

Q,K,V = linear projections of the same input. Divide by √dₖ: as dₖ grows, dot products grow (var ∝ dₖ) → softmax saturates; scaling keeps variance ≈1, gradients healthy.

W4 · Positional Encoding

PE(pos,2i)=sin(pos/10000^{2i/d}) PE(pos,2i+1)=cos(pos/10000^{2i/d})

Added to word embeddings (order has no meaning in attention otherwise). Bounded [−1,1]; different wavelengths per dim let model learn relative positions.

W4 · Multi-Head · Residual · Norm

  • Multi-head: run attention h times in parallel; each head dₖ=d_model/h (512/8=64); concat → W_O. Cost ≈ single head.
  • Residual: x + Sublayer(x) → gradient flow.
  • LayerNorm normalizes over features per token → batch-independent, good for variable-length. BatchNorm normalizes over the batch (bad for NLP).

W4 · FFN · Params · Complexity

  • FFN: position-wise W₂·ReLU(W₁x+b₁)+b₂, usually d_ff=4·d_model. Shape invariance: output shape = input shape.
  • Attention params / layer = 4·d_model² (Wq,Wk,Wv,Wo). LLaMA-7B d=4096 → 4·4096²≈67.1M/layer.
  • Memory complexity O(T²) (attention matrix T×T).

W5 · Causal Mask · Train vs Infer

  • Causal / look-ahead mask: add −∞ to upper triangle before softmax so a token can't attend to future tokens.
  • Training: parallel, teacher-forced, all positions at once. Inference: autoregressive, one token at a time (feed output back).
  • Cross-attention: Q from decoder, K/V from encoder (self-attn: all from same seq).

⭐ W5 · KV Cache 5Q

  • Idea: past tokens' K,V never change → cache them, only compute kₜ,vₜ for the new token. Avoids recomputing the whole prefix.
  • Cost: per-token attention drops O(t²)→O(t) (O(N²) overall).
  • GEMM→GEMV: Qₜ is a single row (B×1×dₖ) → matrix-vector mult, not matrix-matrix.
  • Compute-bound → Memory-bound: arithmetic intensity = FLOPs/Bytes drops; bottleneck becomes moving K/V over memory bus.
KV bytes = 2·precision·n_layers·d_model·n_ctx·B

(×2 = K and V). Lab form: 2·B·seq·n_kv_heads·head_dim·n_layers·bytes.

Ex (lab). B=4, seq=2048, head_dim=128, layers=32, FP16(2B):
MHA 32 heads → 2·4·2048·32·128·32·2 /1024² = 4096 MB.
GQA 8 heads → 1024 MB (4× smaller cache).

W5 · VRAM Planning

Static = params × bytes

LLaMA-7B FP16: 7e9×2 ≈ 14 GB locked. Total VRAM = static weights + KV cache. Long context (n_ctx) & big batch (B) inflate cache → CUDA OOM.

W5 · Decoding: Top-k / Top-p

  • Top-k: keep the k highest-prob tokens (fixed count).
  • Top-p / nucleus: keep smallest set with cumulative prob ≥ p (adaptive count).
  • Filter order: temperature → top-k → top-p → softmax → sample (multinomial).

W6 · BERT: Pretraining setup

  • Self-supervised: labels come from the data itself (a pretext task). Transfer learning: pretrain once → fine-tune on many tasks.
  • Input embedding = Token + Segment + Position (summed).
  • [CLS]: first token; its pooled output → classification. [SEP]: separates two sentences.

W6 · MLM · NSP

  • MLM — the 15% rule: mask 15% of WordPiece tokens. Of those: 80% → [MASK], 10% → random token, 10% → unchanged (so fine-tuning, which has no [MASK], isn't surprised).
  • <15% too weak a signal (slow); >15% destroys context.
  • NSP: binary IsNext / NotNext — does sentence B follow A? (Uses [CLS].)
  • MLM = bidirectional context.

W6 · Fine-tune vs Feature-extract

  • Fine-tuning: update all weights (BERT default).
  • Feature extraction: freeze model, use embeddings as features (ELMo-style).
  • BERT vs ELMo: BERT = deep, jointly bidirectional Transformer; ELMo = shallow concat of two independent LSTMs.

W6 · QA · HF · Probing

  • Extractive QA (SQuAD): predict start and end logits of the answer span in the context.
  • HF pipeline: high-level one-liner. AutoModel: raw hidden states → add your own head (extract [CLS] = last_hidden_state[:,0,:]).
  • BERTology / probing: analyze attention heads & layers → lower layers ≈ syntax, higher ≈ semantics.

W7 · CLM · GPT evolution

  • CLM: predict next token, causal mask. Signal density: every token is a label (dense) vs MLM's ~15% (sparse).
  • Loss = shift logits/labels by one: logits[:-1] vs labels[1:].
  • GPT-1→2→3: ↑scale → zero/few-shot & in-context learning (learn from prompt, no weight update).
  • Open weights (LLaMA) vs closed (GPT-4 API).

W7 · RoPE · RMSNorm · SwiGLU

  • RoPE: rotate Q,K by a position-dependent angle → encodes relative position, extrapolates to longer context.
RMSNorm: y = x/√(mean(x²)+ε) · γ

No mean-centering, no bias → cheaper than LayerNorm.

SwiGLU = (SiLU(xW₁) ⊙ xW₃)·W₂

SiLU(x)=x·σ(x); 3 matrices, params = 3·in·hidden.

W7 · MQA / GQA

  • MHA: each query head has its own K,V head.
  • MQA: 1 shared KV head → smallest cache, small quality hit.
  • GQA: groups of query heads share a KV head → middle ground (LLaMA-2/3).
  • Both shrink KV cache ∝ n_kv_heads (see ⭐ example: 32→8 heads = 4× less).

W7 · Scaling Laws · ICL

  • Kaplan (2020): scale model size faster than data.
  • Chinchilla (2022): scale model & data equally — rule of thumb ~20 tokens/param (70B ⇒ ~1.4T tokens).
  • In-context learning: induction heads / function vectors form task behavior at inference. Context extension via RoPE scaling; omnimodal = text+image+audio.

★ "Spot the WRONG" traps

  • "WordPiece merges most frequent pair" → no, that's BPE.
  • "Clipping fixes vanishing" → no, exploding.
  • "BatchNorm is standard in Transformers" → no, LayerNorm.
  • "Bahdanau uses dot-product" → no, additive (Luong=dot).
  • "BLEU is recall-oriented" → no, precision (ROUGE=recall).
  • "MLM masks 50%" → 15% (80/10/10).
  • "GQA increases KV cache" → decreases.
  • "RMSNorm subtracts the mean" → no (that's LayerNorm).
  • "Kaplan says 20 tokens/param" → that's Chinchilla.
  • "CrossEntropy takes log-probs" → no, logits (NLL takes log-probs).

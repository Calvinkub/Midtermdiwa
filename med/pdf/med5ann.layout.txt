Leaky ReLU function เป็นฟังก์ชันที่พัฒนาต่อยอดมาจาก ReLU function ที่ทําหน้าที่แปลงอินพุตให้เป็นค่าที่อยู่ในช่วงระหว่าง αx ถึง x โดยที่ α เป็น
ค่าคงที่ ๆ มีค่าน้อยมากซึ่งนิยมกําหนดไว้ที่ 0.01 เนื่องจากผลลัพธ์ของอินพุทที่น้อยกว่าไม่เท่ากับ 0 ทําให้หลีกเลี่ยงปัญหาที่พบใน ReLU ได้ นอกจากนี้
กระบวนการเรียนรู้ด้วย Leaky ReLU function รวดเร็วขึ้นกว่า ReLU function

3. Forward Propagation (net = Σxᵢwᵢ + b → activation)

⭐⭐ข้อเขียนหนัก
น้ำหนักมาตรฐาน (โครงข่าย 2-2-2): w1=.15w2=.20w3=.25w4=.30b1=.35 · w5=.40w6=.45w7=.50w8=.55b2=.60
net_h1 = i1·w1 + i2·w2 + b1 · net_h2 = i1·w3 + i2·w4 + b1 · net_o1 = out_h1·w5 + out_h2·w6 + b2 · net_o2 = out_h1·w7 + out_h2·w8 + b2
กฎทำนาย: เลือกคลาสที่ output มากกว่า

D4ReLU (hidden) + Sigmoid (output) · input (0.05, 0.10)

  1. net_h1 = .05·.15 + .10·.20 + .35 = .0075+.02+.35 = 0.3775
  2. net_h2 = .05·.25 + .10·.30 + .35 = .0125+.03+.35 = 0.3925
  3. ReLU: out_h1 = max(0,.3775) = 0.3775, out_h2 = 0.3925 (ทั้งคู่บวก → ไม่เปลี่ยน)
  4. net_o1 = .3775·.40 + .3925·.45 + .60 = .151+.1766+.60 = 0.9276
  5. net_o2 = .3775·.50 + .3925·.55 + .60 = .1888+.2159+.60 = 1.0046
  6. Sigmoid σ(x)=1/(1+e⁻ˣ): out_o1 = 0.7166, out_o2 = 0.7320
ตอบ: output = (0.7166, 0.7320) → o2 > o1 → ทำนาย คลาสที่ 2
กับดัก: ต้องผ่าน ReLU ที่ hidden ก่อน แล้วเอา out_h (ไม่ใช่ net_h) ไปคำนวณ output — จุดพลาดบ่อยที่สุด

D5Logistic (hidden) + Logistic (output) · input (0.05, 0.10)

  1. net_h1 = 0.3775, net_h2 = 0.3925 (เหมือน D4)
  2. Sigmoid ที่ hidden: out_h1 = 1/(1+e⁻·³⁷⁷⁵) = 0.5933, out_h2 = 0.5969
  3. net_o1 = .5933·.40 + .5969·.45 + .60 = 1.1059
  4. net_o2 = .5933·.50 + .5969·.55 + .60 = 1.2249
  5. Sigmoid ที่ output: out_o1 = 0.7514, out_o2 = 0.7729
ตอบ: output = (0.7514, 0.7729) → ทำนาย คลาสที่ 2

D6Linear (hidden) + Linear (output) · input (0.05, 0.10)

  1. Linear f(x)=x: out_h1 = net_h1 = 0.3775, out_h2 = 0.3925
  2. net_o1 = .3775·.40 + .3925·.45 + .60 = 0.9276
  3. net_o2 = .3775·.50 + .3925·.55 + .60 = 1.0046
  4. Linear ที่ output → output = net_o (ค่าอาจ > 1 ได้เพราะไม่มี squashing)
ตอบ: output = (0.9276, 1.0046) → ทำนาย คลาสที่ 2
สังเกต: Linear/Linear ให้ output = net_o ตรง ๆ (0.9276, 1.0046) — เท่ากับ net_o ของ D4 พอดี เพราะ ReLU ไม่เปลี่ยนค่าบวกที่ hidden

D7ReLU (hidden) + Linear (output) · input (0.10, 0.20)

  1. net_h1 = .10·.15 + .20·.20 + .35 = .015+.04+.35 = 0.4050
  2. net_h2 = .10·.25 + .20·.30 + .35 = .025+.06+.35 = 0.4350
  3. ReLU → out_h1 = 0.4050, out_h2 = 0.4350
  4. net_o1 = .4050·.40 + .4350·.45 + .60 = .162+.19575+.60 = 0.9577
  5. net_o2 = .4050·.50 + .4350·.55 + .60 = .2025+.23925+.60 = 1.0417

ตอบ: output = (0.9577, 1.0417) → ทำนาย คลาสที่ 2

D8ReLU (hidden) + Tanh (output) · input (−0.30, 0.40)

  1. net_h1 = (−.30)·.15 + .40·.20 + .35 = −.045+.08+.35 = 0.3850
  2. net_h2 = (−.30)·.25 + .40·.30 + .35 = −.075+.12+.35 = 0.3950
  3. ReLU → out_h1 = 0.3850, out_h2 = 0.3950 (ทั้งคู่ยังบวก)
  4. net_o1 = .3850·.40 + .3950·.45 + .60 = .154+.17775+.60 = 0.9317
  5. net_o2 = .3850·.50 + .3950·.55 + .60 = .1925+.21725+.60 = 1.0097

D10คู่จุดง่าย ๆ (1,3) กับ (4,4)

  2. Manhattan: |1−4|+|3−4| = 3+1 = 4.00
  3. Cosine: (1·4+3·4)/(√(1²+3²)·√(4²+4²)) = 16/(√10·√32) = 16/17.89 = 0.89
ตอบ: Euclidean = 3.16 · Manhattan = 4.00 · Cosine = 0.89

5. Normalization (Max-Min / L1 / Z-score)

D11Max-Min normalization ของ feature "อายุ"

อายุ = 20 ปี · ช่วงของ feature: min = 10, max = 100 · หา x' = (x−min)/(max−min)
  1. x' = (20 − 10)/(100 − 10) = 10/90 = 0.111…
ตอบ: x' ≈ 0.11 (อยู่ในช่วง [0,1])
ทำไมต้อง normalize: ถ้าไม่ทำ feature ช่วงกว้าง (เช่น เงินเดือน 300–30000) จะครอบงำ distance เสมอ — ต้อง normalize ทุก feature ให้ช่วงใกล้กันก่อนวัดระยะทาง

D12L1 normalization ของ histogram

Histogram ภาพ ก = [2, 0, 1, 1] · หา x' = xᵢ / Σxᵢ (ผลรวมเป็น 1)
  1. ผลรวม Σx = 2+0+1+1 = 4
  2. [2/4, 0/4, 1/4, 1/4] = [0.50, 0.00, 0.25, 0.25]
ตอบ: [0.50, 0.00, 0.25, 0.25] (ผลรวม = 1.00)
ใช้เทียบ "สัดส่วน" แทน "จำนวนดิบ" — แก้ปัญหาภาพใหญ่มีค่า histogram สูงกว่าเสมอ

6. Softmax / Entropy / Cross-Entropy / Hinge Loss

⭐

D13Softmax ของ 4 คะแนน

คะแนน (logits): Dog = −3.44, Cat = 1.16, Boat = −0.81, Airplane = 3.91 · หา softmax pᵢ = eˣⁱ / Σeˣ
  1. ยกกำลัง e: Dog e⁻³·⁴⁴ = 0.0321, Cat e¹·¹⁶ = 3.1899, Boat e⁻⁰·⁸¹ = 0.4449, Airplane e³·⁹¹ = 49.8990
  2. ผลรวม Σ = 0.0321+3.1899+0.4449+49.8990 = 53.5659
  3. หาร: Dog 0.0006, Cat 0.0596, Boat 0.0083, Airplane 0.9315
ตอบ: p = (Dog 0.0006, Cat 0.0596, Boat 0.0083, Airplane 0.9315) · รวม = 1 · ทำนาย Airplane

D14Entropy & Cross-Entropy (3 คลาส)

Softmax 3 คลาส: Dog = 0.0006, Cat = 0.0596, Airplane = 0.9315 · คลาสจริง (actual) = Airplane
หา Entropy = −Σpᵢ·log₂pᵢ และ Cross-Entropy = −log₂(p_correct)
  1. Entropy = −[0.0006·log₂0.0006 + 0.0596·log₂0.0596 + 0.9315·log₂0.9315]
  2. = −[0.0006·(−10.70) + 0.0596·(−4.07) + 0.9315·(−0.1024)] = −[−0.0064 −0.2427 −0.0954] = 0.3443
  3. Cross-Entropy (correct = Airplane, p = 0.9315): −log₂(0.9315) = −(−0.1024) = 0.1024
ตอบ: Entropy ≈ 0.3443 · Cross-Entropy ≈ 0.1024 (ทำนายถูกและมั่นใจมาก → ค่าน้อย ใกล้ 0)
กับดัก: Entropy ใช้ pᵢ (predicted) คูณ log ของตัวเองทุกคลาส; Cross-Entropy ใช้ qᵢ (actual, one-hot) → เหลือแค่พจน์ของคลาสที่ถูก. สูตรคล้ายกันมาก อย่าสลับ

D15Hinge Loss

Softmax: Dog = 0.0006, Cat = 0.0596, Airplane = 0.9315 (ถูก) · หา Loss = Σ max(0, sⱼ − s_correct + 1) รวมทุกคลาสผิด
  1. คลาสถูก s_correct = Airplane = 0.9315
  2. Dog: max(0, 0.0006 − 0.9315 + 1) = max(0, 0.0691) = 0.0691
  3. Cat: max(0, 0.0596 − 0.9315 + 1) = max(0, 0.1281) = 0.1281
  4. รวม: 0.0691 + 0.1281 = 0.1972 ≈ 0.20
ตอบ: Hinge Loss ≈ 0.20 (ค่าน้อย = ทำนายดี มั่นใจมาก)

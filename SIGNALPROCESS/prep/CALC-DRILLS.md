```
Wₙ = e^{−j2π/N}          W₂ = −1     W₄ = −j     W₈ = 0.707 − 0.707j
(−j)⁰=1  (−j)¹=−j  (−j)²=−1  (−j)³=j   แล้ววนซ้ำ (เอาเลขชี้กำลัง mod 4)
เช็คเร็ว:  X[0] = ผลรวมทุกตัว   |   X[N/2] = ผลรวมสลับเครื่องหมาย (+−+−…)
ขนาด |x+jy| = √(x²+y²)    เฟส = tan⁻¹(y/x)  (ระวัง quadrant)
DFT ใช้ N² คูณ  |  FFT ใช้ N·log₂N คูณ
```

# 🟦 ชุด A — 4-point DFT (คำนวณมือ ต้องทำได้ 100%)

## A1 ⭐ [ตัวอย่างแม่แบบ] x[n] = {2, 3, 4, 4}
**โจทย์:** จงหา DFT 4 จุด พร้อมขนาดและเฟส

**วิธีทำ:**
**ขั้น 1 — หา Wₙ:** N=4 → `W₄ = e^{−j2π/4} = e^{−jπ/2} = cos(π/2) − j sin(π/2) = −j`

**ขั้น 2 — เขียนสมการ:** `X[k] = Σ_{n=0}^{3} x[n](−j)^{kn}`, k=0,1,2,3

**ขั้น 3 — แทน k ทีละค่า** (จำ: เลขชี้กำลัง kn เอา mod 4 ก่อน):

`k=0:` เลขชี้กำลัง = 0 หมด → `(−j)⁰=1`
$$X[0] = 2(1)+3(1)+4(1)+4(1) = 13$$

`k=1:` kn = 0,1,2,3 → `(−j)⁰,(−j)¹,(−j)²,(−j)³ = 1,−j,−1,j`
$$X[1] = 2(1)+3(−j)+4(−1)+4(j) = 2 − 3j − 4 + 4j = -2 + j$$

`k=2:` kn = 0,2,4,6 → mod4 = 0,2,0,2 → `1,−1,1,−1`
$$X[2] = 2(1)+3(−1)+4(1)+4(−1) = 2 − 3 + 4 − 4 = -1$$

`k=3:` kn = 0,3,6,9 → mod4 = 0,3,2,1 → `1,j,−1,−j`
$$X[3] = 2(1)+3(j)+4(−1)+4(−j) = 2 + 3j − 4 − 4j = -2 - j$$

**ตอบ:** `X[k] = {13, −2+j, −1, −2−j}`

**ขั้น 4 — ขนาด & เฟส:**
| k | X[k] | ขนาด √(x²+y²) | เฟส |
|---|---|---|---|
| 0 | 13 | 13 | 0° |
| 1 | −2+j | √(4+1)=**√5≈2.24** | 180°−26.57°=**153.43°** |
| 2 | −1 | 1 | 180° |
| 3 | −2−j | **√5≈2.24** | **−153.43°** (206.57°) |

> ⚠️ สไลด์เขียน |X|={13,**5**,1,**5**} — เลข 5 **ผิด** (นั่นคือ |X|²). ที่ถูก = **√5 ≈ 2.24**. แสดง √(2²+1²) ให้เห็นในกระดาษเสมอ
> 💡 **สังเกต conjugate symmetry:** `X[3]=X[1]*` (สัญญาณจริง → spectrum สมมาตรเชิงซ้อน) ใช้เช็คคำตอบได้

# 🟩 ชุด B — DTFS (สัมประสิทธิ์ aₖ)

## B1 ⭐ x[n] = {3, 2, −2, 1}, N=4 (หา aₖ)
**โจทย์:** จงหาสัมประสิทธิ์ฟูเรียร์ DTFS ทั้งหมด

**วิธีทำ:** `aₖ = (1/N)Σ x[n]e^{−jkω₀n}` โดย `ω₀=2π/4`, `e^{−jkω₀n}=(−j)^{kn}` (เหมือน DFT แต่หาร N)
> 💡 **ทางลัด:** `aₖ = X[k]/N` — คำนวณ DFT ก่อน แล้วหาร 4

DFT ของ {3,2,−2,1}:
- `X[0]=3+2−2+1=4`
- `X[1]=3(1)+2(−j)+(−2)(−1)+1(j)=3−2j+2+j=5−j`
- `X[2]=3(1)+2(−1)+(−2)(1)+1(−1)=3−2−2−1=−2`
- `X[3]=3(1)+2(j)+(−2)(−1)+1(−j)=3+2j+2−j=5+j`

**aₖ = X[k]/4:** `a₀=1, a₁=(5−j)/4=1.25−0.25j, a₂=−0.5, a₃=1.25+0.25j`

**ตอบ:** `aₖ = {1, 1.25−0.25j, −0.5, 1.25+0.25j}`
ขนาด: `|a₁|=√(1.25²+0.25²)=√1.625≈1.27`, `|a₂|=0.5`

# 🟥 ชุด C — 8-point DFT & Zero-padding

## C1 ⭐ x[n]={2,3,4,4,0,0,0,0} (8-point DFT — เทียบกับ A1)
**โจทย์:** จงหา 8-point DFT (นี่คือ {2,3,4,4} ที่เติม 0 = zero-padding)

**วิธีทำ:** `N=8 → W₈=e^{−jπ/4}=0.707−0.707j` · เพราะ x[4..7]=0 เหลือ 4 พจน์แรก
`X[k] = 2·W₈^{0} + 3·W₈^{k} + 4·W₈^{2k} + 4·W₈^{3k}`

ค่า `W₈^m` ที่ต้องใช้ (วนคาบ 8): `W₈⁰=1, W₈¹=0.707−0.707j, W₈²=−j, W₈³=−0.707−0.707j, W₈⁴=−1, W₈⁵=−0.707+0.707j, W₈⁶=j, W₈⁷=0.707+0.707j`

- `X[0]=2+3+4+4=13`
- `X[1]=2+3(0.707−0.707j)+4(−j)+4(−0.707−0.707j)=2+2.12−2.12j−4j−2.83−2.83j=1.29−8.95j`
- `X[2]=2+3(−j)+4(−1)+4(j)=2−3j−4+4j=−2+j`
- `X[3]=2+3(−0.707−0.707j)+4(j)+4(0.707−0.707j)=2−2.12−2.12j+4j+2.83−2.83j=2.71−0.95j`
- `X[4]=2+3(−1)+4(1)+4(−1)=2−3+4−4=−1`
- `X[5]=X[3]* =2.71+0.95j` · `X[6]=X[2]*=−2−j` · `X[7]=X[1]*=1.29+8.95j` (ใช้ conjugate symmetry!)

**ตอบ:** `X[k]={13, 1.29−8.95j, −2+j, 2.71−0.95j, −1, 2.71+0.95j, −2−j, 1.29+8.95j}`
ขนาด: `{13, 9.04, 2.24, 2.87, 1, 2.87, 2.24, 9.04}`

> **จุดของ zero-padding:** เทียบ 4-DFT {13, 2.24, 1, 2.24} กับ 8-DFT — spectrum **หนาแน่นขึ้น (density เพิ่ม)** เห็นรายละเอียดมากขึ้น แต่ไม่ได้ข้อมูลใหม่
> ⚠️ สไลด์เขียนขนาด "5" ที่ k=2,6 — ผิด ควรเป็น **2.24 (=√5)**

# 🟪 ชุด D — FFT (Part 3 ตัวจริง!)

## D1 ⭐⭐ ใช้ FFT หา X[k] ของ x[n]={9,4,6,0,1,0,6,4} (N=8)
**วิธีทำแบบ decimation (แตกครึ่ง even/odd):**

**ขั้น 1 — bit reversal จัดลำดับ input:** index 0..7 = 000..111 → กลับบิต
`0→0, 1→4, 2→2, 3→6, 4→1, 5→5, 6→3, 7→7`
ลำดับใหม่: `x[0],x[4],x[2],x[6],x[1],x[5],x[3],x[7] = 9,1,6,6,4,0,0,4`

**ขั้น 2 — Stage 1 (2-point butterfly, บวก/ลบเป็นคู่):**
- (9,1) → 9+1=10, 9−1=8
- (6,6) → 12, 0
- (4,0) → 4, 4
- (0,4) → 4, −4
→ ได้ `{10,8,12,0,4,4,4,−4}`

**ขั้น 3 — Stage 2 (butterfly ระยะ 2, ใช้ W₄):** จับกลุ่มละ 4; ตัวคู่ตำแหน่งบวก/ลบตัวห่าง 2 โดยตัวล่างคูณ `W₄^m` (m=0→1, m=1→−j)
กลุ่ม 1 {10,8,12,0}: `top,bot=(10,12·1),(8,0·(−j))` → `[10+12, 8+0, 10−12, 8−0] = [22, 8, −2, 8]`
กลุ่ม 2 {4,4,4,−4}: `top,bot=(4,4·1),(4,(−4)(−j))` → `[4+4, 4+4j, 4−4, 4−4j] = [8, 4+4j, 0, 4−4j]`
→ `{22, 8, −2, 8, 8, 4+4j, 0, 4−4j}`

**ขั้น 4 — Stage 3 (butterfly ระยะ 4, ใช้ W₈):** บน={22,8,−2,8}, ล่าง={8,4+4j,0,4−4j} · ตัวล่างคูณ `W₈^0,W₈^1,W₈^2,W₈^3 = 1, (0.707−0.707j), −j, (−0.707−0.707j)`
- twiddle: `8·1=8` · `(4+4j)(0.707−0.707j)=5.66` · `0·(−j)=0` · `(4−4j)(−0.707−0.707j)=−5.66`
- `X[0]=22+8=30` · `X[1]=8+5.66=13.66` · `X[2]=−2+0=−2` · `X[3]=8−5.66=2.34`
- `X[4]=22−8=14` · `X[5]=8−5.66=2.34` · `X[6]=−2−0=−2` · `X[7]=8+5.66=13.66`

**ตอบ (ตรวจด้วย DFT):** `X[k]={30, 13.6569, −2, 2.3431, 14, 2.3431, −2, 13.6569}`
เช็คเร็ว: `X[0]=9+4+6+0+1+0+6+4=30` ✓ · `X[4]=9−4+6−0+1−0+6−4=14` ✓ · X[k] จริงล้วน (x[n] สมมาตร)

## D2 ⭐ [คำถามที่ออกชัวร์] นับจำนวนการคูณ
**โจทย์:** 8-point FFT ใช้การคูณกี่ครั้ง? เทียบกับ DFT ประหยัดกี่เท่า?

**วิธีทำ:**
- จำนวน stage = `log₂N = log₂8 = 3`
- butterfly ต่อ stage = `N/2 = 4`
- คูณต่อ butterfly = 2
- **FFT: `(N/2)·log₂N·2 = N·log₂N = 8×3 = 24 ครั้ง`**
- **DFT: `N² = 8² = 64 ครั้ง`**
- ประหยัด = `64/24 ≈ 2.67 เท่า`

**ตอบ:** FFT 24 ครั้ง, DFT 64 ครั้ง, เร็วขึ้น ~2.67 เท่า

## D3 [ฝึกเอง] N=1024 FFT ใช้กี่ครั้ง เทียบ DFT?
<details><summary>👉 เฉลย</summary>

FFT = `N log₂N = 1024 × 10 = 10,240` · DFT = `N² = 1,048,576` · เร็วขึ้น **102 เท่า** — นี่คือเหตุผลที่ FFT ปฏิวัติวงการ
</details>

# 🟨 ชุด E — Fourier Series (ต่อเนื่อง)

## E1 ⭐ Square wave: f(t)=−1 (−π<t<0), +1 (0<t<π), คาบ 2π
**วิธีทำ:**
**ขั้น 1:** T=2π → `ω=2π/T=1`
**ขั้น 2:** เป็น **odd function** (f(−t)=−f(t)) → รู้ทันทีว่า **a₀=0, aₙ=0** เหลือแต่ bₙ (ประหยัดเวลา!)
**ขั้น 3:** `bₙ=(2/T)∫f sin(nt)dt = (2/2π)[∫_{−π}^0(−1)sin(nt)dt + ∫_0^π(1)sin(nt)dt]`
= `(1/π)·2∫_0^π sin(nt)dt` (ใช้สมมาตร) = `(2/π)·[−cos(nt)/n]_0^π = (2/π)·(1−cos nπ)/n`
- n คู่: cos nπ=1 → bₙ=0
- n คี่: cos nπ=−1 → bₙ=`(2/π)(2/n)=4/(nπ)`

**ตอบ:** `f(t) = (4/π)(sin t + ⅓sin3t + ⅕sin5t + …)` — **มีแต่ harmonic คี่**

## E2 [ผลลัพธ์ให้จำหน้าตา — สไลด์]
| สัญญาณ | Fourier Series |
|---|---|
| Square (0→1, มี DC) | `f(t)=3/2+(2/π)(sin t+⅓sin3t+⅕sin5t+…)` |
| Triangle (even) | `f(t)=π/2−(4/π)(cos t+⅑cos3t+1/25 cos5t+…)` |
| Sawtooth | `f(t)=2(sin t−½sin2t+⅓sin3t−¼sin4t+…)` |

> **เช็ค:** even signal → cos เท่านั้น (Triangle) · odd signal → sin เท่านั้น (Square, Sawtooth) · ค่าเฉลี่ยไม่เป็น 0 → มีพจน์ a₀ (DC)

# 🟫 ชุด F — DTFT

## F1 ⭐ x[n]={1,2,3,2,1} จัดกลางที่ n=−2..2
**วิธีทำ:** `X(ω)=Σx[n]e^{−jωn}`
= `1e^{j2ω}+2e^{jω}+3+2e^{−jω}+1e^{−j2ω}`
จับคู่สมมาตร ใช้ `e^{jθ}+e^{−jθ}=2cosθ`:
= `(e^{j2ω}+e^{−j2ω})+2(e^{jω}+e^{−jω})+3`
= **`2cos2ω+4cosω+3`**
มีแต่ส่วนจริง → `|X(ω)|=|2cos2ω+4cosω+3|`, เฟส `∠X(ω)=0`

> **เคล็ด:** สัญญาณ discrete **สมมาตร (even)** รอบ n=0 → DTFT เป็น **cos ล้วน (real)** เสมอ

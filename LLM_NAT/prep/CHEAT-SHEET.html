Building LLM-Powered Apps — Cheat Sheet L1–L6 · concept exam (no coding) · จับกับดัก "ข้อใดผิด"

L1 · Model & Roles

  • LLM = next-token predictor (prob dist → sample). decoder-only/autoregressive. attention = คำมองคำอื่นชั่งน้ำหนัก (context)
  • Roles: system=rules/persona (ตั้งครั้งเดียว) · user=input · assistant=prior replies (memory)
  • Stateless — ไม่มีความจำ; resend messages list ทุก call

L1 · Sampling & Prompting

  • temperature: หาร logit ก่อน softmax. 0=deterministic (greedy), สูง=creative. tune temp หรือ top_p ไม่ใช่ทั้งคู่
  • logit → softmax → prob (sum=1); top_p=nucleus; max_tokens; stop
  • zero/few-shot(copy format)/CoT(math)/system. in-context learning (weights frozen)

L1 · Streaming trap

  • ลด perceived latency + หยุดได้ — ไม่เพิ่ม generation speed/accuracy
  • fix by symptom: few-shot=format · CoT=logic · grounding+"say I don't know"=hallucination · delimit data=injection · self-consistency=majority vote (high-stakes)

L1 · Tokens & Cost

  • Token ≈ ~4 chars (rule of thumb); ไทย/โค้ด แพงกว่า (token/char มากกว่า)
  • Context window จำกัด; stateless → resend history ทุก turn → cost ไต่ขึ้น; oldest ถูก truncate = "ลืม"
  • logit→softmax; temp หรือ top_p (top_k=ญาติ); stop=หยุดก่อน parse; temp=0 ไม่การันตี 100% (FP)

L2 · JSON & Validation

  • JSON mode = syntax เท่านั้น ≠ shape. Valid JSON ≠ valid data. class proxy IGNORES response_format → prompt→parse→validate→repair
  • json.loads (ไม่ใช่ eval=RCE). bool trap: isinstance(True,int)=True → ใช้ type(qty) is int
  • 3 layers: parse → schema/type → semantic (qty=-3, discount 1.5 → semantic เท่านั้น). Pydantic = schema+validator; Optional=absent/null
  • repair loop: feed error back, cap ~3. local(fence/comma) vs loop(semantic)

L3 · HTTP Status Codes ออกบ่อย

Codeความหมาย (บริบทวิชานี้)
200OK — สำเร็จ (chat reply กลับปกติ)
201Created — สร้าง resource ใหม่สำเร็จ
400Bad Request — JSON malformed จริงๆ
401Unauthorized — ไม่มี/ผิด auth (API key)
403Forbidden — auth ผ่านแต่ไม่มีสิทธิ์
404Not Found — หา endpoint/resource ไม่เจอ (เช่น conversation_id ไม่รู้จัก)
422Unprocessable Entity — JSON parse ได้ แต่ field fail validation (Pydantic) ⭐
429Too Many Requests — ชน rate limit (+ Retry-After) ⭐
500Internal Server Error — bug ในโค้ดคุณ (retry ไม่ช่วย)
502Bad Gateway — upstream (model proxy) error ⭐
503Service Unavailable — server overload/ล่มชั่วคราว
504Gateway Timeout — model timeout ⭐

2xx สำเร็จ · 4xx your fault (client) · 5xx our fault (server). chat = POST (side effect). ⭐ = รู้ให้ขึ้นใจ

L3 · Backend

  • key server-side (browser→API คุณ→model); เรียก provider จาก browser = key รั่ว
  • router→service→repository (HTTP → logic → DB). handler async (sync block = freeze loop)
  • Pydantic reject ที่ edge → 422 (body=list of field errors; HTTPException=string)
  • token bucket: เติม token/เวลา, ว่าง→429. idempotency key = retry POST ปลอดภัย
  • Alembic: versioned/ordered/reversible; revision→upgrade head

L4 · SSE trap

  • SSE = one-way server→client over HTTP (token stream). WebSocket=2-way (เกินจำเป็น)
  • Header text/event-stream; frame = data: ... จบ blank line \n\n; [DONE] sentinel
  • newline trap: token "\n" → JSON-wrap ทุก token (json.dumps ไม่ใช่ {tok!r})
  • buffer trap: chunks≠frames → buffer+split \n\n+keep partial
  • deploy "clumps" = buffering proxy → X-Accel-Buffering:no. error mid-stream = yield error frame (status=200 แล้ว)

L4 · Reactivity

  • เปลี่ยน state → UI redraw เอง. reassign ไม่ใช่ mutate: messages=[...messages,x] (ไม่ใช่ .push)
  • $state/$derived/$effect. Stop=AbortController+server is_disconnected()

L5 · Cosine calc

  • มุม ไม่ใช่ระยะทาง. +1 เหมือน · 0 ไม่เกี่ยว · −1 ตรงข้าม. NN=สูงสุด
  • นิยาม: ,
  • a=[1,0,1] b=[1,1,0]:
  • real embeddings unrelated ~0.3–0.5 → rank อย่า threshold

L5 · Vector Store

  • embedding=fixed-length vector (bge-m3 1024-dim). direction=meaning. same model query+docs (space mismatch=พังบ่อยสุด)
  • pgvector <=> = cosine DISTANCE (ต่ำ=ใกล้) → ORDER BY ... ASC (similarity=DESC)
  • ANN (HNSW/IVFFlat) แลก recall เพื่อspeed. brute-force ok ถึงหมื่นตัว
  • chunk 200–500 tok, 10–20% overlap, +metadata (cite+filter)

⭐ L6 · RAG Debug Ladder

  • 1. print top-k (gold chunk มาไหม?) ← เช็คก่อนเสมอ
  • 2. อยู่ใน index? (stale/chunking) 3. vocab mismatch? →embeddings
  • 4. เมิน? lost in middle→k เล็ก, best first 5. ยังมั่ว? "ONLY context"+temp0

"Most bad RAG = bad retrieval, not a bad model"

L6 · RAG core

  • retrieve-then-read: embed q→top-k→stuff prompt→answer. อ่านแค่ top-k
  • RAG vs fine-tune: no retrain, update index, cite (private/changing data)
  • min_score floor→"I don't know". prompt "ONLY context"+cite [1][2]+temp0
  • k=40 แย่กว่า k=4 (noise+lost-in-middle). k เล็ก 3–5

  • "JSON mode การันตี shape" → syntax เท่านั้น
  • "message ผิด type → 400/500" → 422
  • "upstream error → 200" → 502
  • "streaming ต้อง WebSocket" → SSE พอ
